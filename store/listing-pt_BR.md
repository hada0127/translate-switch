# Translate Switch - Alternador de tradução — página na Chrome Web Store (português do Brasil)

## Summary (≤132 chars)
Traduz só o idioma escolhido com o tradutor no dispositivo do Chrome. ⌘K / Ctrl+K liga e desliga; passe o mouse para ver o original.

## Description
O Translate Switch substitui apenas as frases em idioma estrangeiro de uma página pelo seu idioma e deixa todo o resto intacto. Ele não recarrega nem redesenha a página; usa o tradutor integrado do Chrome, que roda no próprio dispositivo, então o conteúdo da página nunca sai do seu computador.

Pressione ⌘K (Mac) / Ctrl+K (Windows) para ativar ou desativar a tradução da página que você está lendo. Quando o alternador já está na página, não é preciso clicar no ícone da barra de ferramentas.

Recursos
- O atalho ⌘K (Mac) / Ctrl+K (Windows) liga e desliga a tradução na hora; funciona com qualquer layout de teclado.
- Tradução no dispositivo (Translator API integrada do Chrome). Nenhum conteúdo da página é enviado a servidores.
- O texto traduzido aparece com fundo claro e sublinhado pontilhado; passe o mouse para ver o original e o idioma detectado.
- Idioma de origem: detecção automática ou um idioma fixo. Destino: qualquer um dos 39 idiomas compatíveis com o Chrome (o padrão é o idioma do navegador).
- Ative por site ou permita todos os sites de uma vez. A tradução automática ao abrir a página vale só para os sites em que você a configurou; em um site novo, o alternador aparece e você ativa a tradução com ⌘K / Ctrl+K ou pelo próprio alternador.
- Botão do alternador que pode ser movido e ocultado; cor de destaque configurável.
- Interface disponível em 40 idiomas.

Primeiro uso
1. Clique no ícone e baixe o modelo de tradução uma única vez em “Baixar modelo” (por par de idiomas; compartilhado em todo o Chrome).
2. Clique em “Ativar” (ou pressione ⌘K / Ctrl+K) para traduzir a página atual. Permita o acesso ao site se quiser que o alternador apareça automaticamente na próxima visita.
3. Em cada site novo, o Chrome exige um clique dentro da página antes da primeira tradução; pressione o alternador quando ele mostrar “Clique para traduzir”.

Permissões
- storage: salva suas configurações.
- activeTab, scripting: coloca o alternador na guia em que você clicou no ícone.
- Acesso opcional a sites: apenas aos sites que você permitir explicitamente, para que o alternador apareça automaticamente da próxima vez.

Requer o Chrome 138 ou mais recente. A qualidade da tradução é a do tradutor integrado do Chrome.
