# Translate Switch - מתג תרגום — דף בחנות האינטרנט של Chrome (עברית)

## Summary (≤132 chars)
מתרגם רק את השפה שבחרתם בעזרת המתרגם המובנה של Chrome, ישירות במכשיר. ⌘K / Ctrl+K להפעלה ולכיבוי; ריחוף בעכבר מציג את המקור.

## Description
Translate Switch מחליף בשפה שלכם רק את המשפטים בשפה זרה שבדף, ומשאיר את כל השאר כמו שהוא. הדף לא נטען מחדש ולא מוצג מחדש; התרגום נעשה בעזרת המתרגם המובנה של Chrome שפועל במכשיר עצמו, כך שתוכן הדפים אף פעם לא יוצא מהמחשב שלכם.

לחצו על ⌘K (Mac) / Ctrl+K (Windows) כדי להפעיל או לכבות את התרגום בדף שאתם קוראים. כשהמתג כבר נמצא בדף, אין צורך ללחוץ על הסמל בסרגל הכלים.

תכונות
- קיצור הדרך ⌘K (Mac) / Ctrl+K (Windows) מפעיל ומכבה את התרגום מיד, בכל פריסת מקלדת.
- תרגום במכשיר (Translator API המובנה ב-Chrome). שום תוכן מהדף לא נשלח לשרת כלשהו.
- טקסט מתורגם מודגש ברקע בהיר ובקו תחתון מנוקד; ריחוף מעליו בעכבר מציג את המקור ואת השפה שזוהתה.
- שפת מקור: זיהוי אוטומטי או שפה קבועה. שפת יעד: כל אחת מ-39 השפות ש-Chrome תומך בהן (ברירת המחדל היא שפת הדפדפן).
- הפעלה לפי אתר, או הרשאה חד-פעמית לכל האתרים. תרגום אוטומטי בפתיחת דף חל רק על אתרים שהגדרתם לכך; באתר חדש המתג מופיע, ומפעילים אותו ב-⌘K / Ctrl+K או במתג עצמו.
- לחצן מתג שאפשר להזיז ולהסתיר; צבע הדגשה שניתן לשנות.
- ממשק ב-40 שפות.

שימוש ראשון
1. לחצו על הסמל והורידו את מודל התרגום פעם אחת („הורדת מודל”; פעם אחת לכל צמד שפות, משותף לכל Chrome).
2. לחצו על „הפעלה” (או על ⌘K / Ctrl+K) כדי לתרגם את הדף הנוכחי. אשרו גישה לאתר אם אתם רוצים שהמתג יופיע אוטומטית בביקור הבא.
3. בכל אתר חדש Chrome דורש לחיצה אחת בתוך הדף לפני התרגום הראשון; לחצו על המתג כשמופיע עליו „לחיצה לתרגום”.

הרשאות
- storage: שומרת את ההגדרות שלכם.
- activeTab, scripting: מוסיפות את המתג לכרטיסייה שבה לחצתם על הסמל.
- גישה אופציונלית לאתרים: רק לאתרים שאישרתם במפורש, כדי שהמתג יופיע אוטומטית בפעם הבאה.

נדרש Chrome 138 ואילך. איכות התרגום היא איכות המתרגם המובנה של Chrome.
