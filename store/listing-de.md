# Translate Switch - Übersetzungsschalter — Chrome Web Store-Eintrag (Deutsch)

## Summary (≤132 chars)
Übersetzt nur die gewählte Sprache mit Chromes On-Device-Übersetzer. ⌘K / Ctrl+K schaltet um; Maus darüber zeigt das Original.

## Description
Translate Switch ersetzt auf einer Seite nur die fremdsprachigen Sätze durch Ihre Sprache und lässt alles andere unverändert. Die Seite wird weder neu geladen noch neu aufgebaut: Die Übersetzung übernimmt Chromes integrierter Übersetzer direkt auf dem Gerät, sodass Seiteninhalte Ihren Computer nie verlassen.

Drücken Sie ⌘K (Mac) / Ctrl+K (Windows), um die Übersetzung der gerade geöffneten Seite ein- oder auszuschalten. Sobald der Schalter auf einer Seite sitzt, müssen Sie nicht mehr auf das Symbol in der Symbolleiste klicken.

Funktionen
- Tastenkürzel ⌘K (Mac) / Ctrl+K (Windows) schaltet die Übersetzung sofort ein und aus – mit jedem Tastaturlayout.
- Übersetzung auf dem Gerät (Chromes integrierte Translator API). Es werden keine Seiteninhalte an einen Server gesendet.
- Übersetzter Text wird mit hellem Hintergrund und gepunkteter Unterstreichung markiert; fahren Sie mit der Maus darüber, um das Original samt erkannter Sprache zu sehen.
- Ausgangssprache: automatische Erkennung oder eine feste Sprache. Zielsprache: jede der 39 von Chrome unterstützten Sprachen (standardmäßig Ihre Browsersprache).
- Pro Website einschalten oder einmal alle Websites erlauben. Die automatische Übersetzung beim Öffnen einer Seite gilt nur für Websites, für die Sie sie eingestellt haben; auf einer neuen Website erscheint der Schalter, und Sie schalten mit ⌘K / Ctrl+K oder über den Schalter ein.
- Verschiebbarer, ausblendbarer Schalter; Markierungsfarbe einstellbar.
- Oberfläche in 40 Sprachen.

Erste Schritte
1. Klicken Sie auf das Symbol und laden Sie das Übersetzungsmodell einmalig herunter („Modell herunterladen“; einmal pro Sprachpaar, in ganz Chrome gemeinsam genutzt).
2. Klicken Sie auf „Einschalten“ (oder drücken Sie ⌘K / Ctrl+K), um die aktuelle Seite zu übersetzen. Erlauben Sie den Websitezugriff, wenn der Schalter beim nächsten Besuch automatisch erscheinen soll.
3. Auf jeder neuen Website verlangt Chrome vor der ersten Übersetzung einen Klick in die Seite; drücken Sie den Schalter, wenn er „Zum Übersetzen klicken“ anzeigt.

Berechtigungen
- storage: speichert Ihre Einstellungen.
- activeTab, scripting: fügt den Schalter in den Tab ein, in dem Sie auf das Symbol geklickt haben.
- Optionaler Websitezugriff: nur für Websites, die Sie ausdrücklich erlauben, damit der Schalter beim nächsten Mal automatisch erscheint.

Erfordert Chrome 138 oder neuer. Die Übersetzungsqualität entspricht der des integrierten Chrome-Übersetzers.
