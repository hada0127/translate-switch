# Translate Switch - Interrupteur de traduction — fiche Chrome Web Store (français)

## Summary (≤132 chars)
Traduit uniquement la langue choisie, en local, via le traducteur de Chrome. ⌘K / Ctrl+K pour activer ; survolez pour l'original.

## Description
Translate Switch remplace uniquement les phrases en langue étrangère d'une page par votre langue et laisse tout le reste intact. La page n'est ni rechargée ni reconstruite : la traduction est assurée par le traducteur intégré de Chrome, directement sur l'appareil, de sorte que le contenu des pages ne quitte jamais votre ordinateur.

Appuyez sur ⌘K (Mac) / Ctrl+K (Windows) pour activer ou désactiver la traduction de la page que vous lisez. Une fois l'interrupteur présent sur une page, inutile de cliquer sur l'icône de la barre d'outils.

Fonctionnalités
- Le raccourci ⌘K (Mac) / Ctrl+K (Windows) active ou désactive la traduction instantanément, quelle que soit la disposition du clavier.
- Traduction sur l'appareil (API Translator intégrée à Chrome). Aucun contenu de page n'est envoyé à un serveur.
- Le texte traduit est mis en évidence par un fond clair et un soulignement en pointillés ; survolez-le pour voir l'original et la langue détectée.
- Langue source : détection automatique ou langue fixe. Langue cible : l'une des 39 langues prises en charge par Chrome (par défaut, la langue de votre navigateur).
- Activation site par site, ou autorisation unique pour tous les sites. La traduction automatique à l'ouverture d'une page ne s'applique qu'aux sites pour lesquels vous l'avez configurée ; sur un nouveau site, l'interrupteur s'affiche et vous l'activez avec ⌘K / Ctrl+K ou d'un clic sur l'interrupteur.
- Bouton interrupteur déplaçable et masquable ; couleur de surlignage personnalisable.
- Interface disponible en 40 langues.

Première utilisation
1. Cliquez sur l'icône et téléchargez une fois le modèle de traduction (« Télécharger le modèle » ; une fois par paire de langues, partagé dans tout Chrome).
2. Cliquez sur « Activer » (ou appuyez sur ⌘K / Ctrl+K) pour traduire la page actuelle. Autorisez l'accès au site si vous voulez que l'interrupteur s'affiche automatiquement lors de votre prochaine visite.
3. Sur chaque nouveau site, Chrome exige un clic dans la page avant la première traduction ; appuyez sur l'interrupteur lorsqu'il indique « Cliquez pour traduire ».

Autorisations
- storage : enregistre vos paramètres.
- activeTab, scripting : ajoute l'interrupteur à l'onglet dans lequel vous avez cliqué sur l'icône.
- Accès facultatif aux sites : uniquement pour les sites que vous autorisez explicitement, afin que l'interrupteur s'affiche automatiquement la prochaine fois.

Nécessite Chrome 138 ou version ultérieure. La qualité de traduction est celle du traducteur intégré de Chrome.
