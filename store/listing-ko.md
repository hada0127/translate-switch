# 번역 스위치 — Chrome 웹 스토어 등록 정보 (한국어)

## 이름
번역 스위치 - Translate Switch

## 요약 (132자 이내)
고른 사이트에서 정한 언어만 Chrome 내장 번역기로 바꿔 보여 줍니다. 번역은 이 컴퓨터 안에서 처리되며, 원문은 마우스를 올리면 볼 수 있습니다.

## 설명
외국어가 섞인 페이지에서 그 외국어 부분만 내 언어로 바꿔 보여 주는 확장 프로그램입니다. 페이지 전체를 통째로 번역하는 것이 아니라, 일본어·영어 등 정해 둔(또는 자동으로 감지한) 언어의 문장만 바꾸고 나머지는 그대로 둡니다.

단축키 ⌘K(맥) / Ctrl+K(윈도우) 한 번으로 보고 있는 페이지의 번역을 바로 켜고 끕니다. 스위치가 붙은 페이지라면 아이콘을 누를 필요가 없습니다.

■ 이런 분께
- 한국어 그룹웨어·메일에 섞여 오는 일본어·영어를 빠르게 읽고 싶을 때
- 외국 사이트를 원문 레이아웃 그대로 두고 문장만 바꿔 보고 싶을 때
- 번역 내용이 외부 서버로 나가는 것이 꺼려질 때

■ 특징
- 단축키 ⌘K(맥) / Ctrl+K(윈도우)로 바로 켜고 끕니다. 한글·일본어 자판에서도 동작합니다.
- Chrome 내장 번역기(기기 내 처리)를 씁니다. 페이지 내용이 외부로 전송되지 않습니다.
- 번역된 부분은 옅은 배경과 점선 밑줄로 표시되고, 마우스를 올리면 원문이 툴팁으로 보입니다.
- 원문 언어는 자동 감지 또는 직접 지정, 번역 언어는 Chrome이 지원하는 39개 언어 중에서 고를 수 있습니다(기본값은 브라우저 언어).
- 사이트별로 켜고 끄거나, 한 번 허용해 모든 사이트에서 쓸 수 있습니다. 페이지를 열 때 자동 번역은 사이트별로 정한 곳에서만 켜집니다(처음 가는 사이트는 스위치만 붙고, ⌘K / Ctrl+K 나 스위치로 켭니다).
- 화면의 스위치(알약 버튼)는 위치를 바꾸거나 숨길 수 있고, 표시 색상도 바꿀 수 있습니다.
- 40개 언어 화면을 지원합니다.

■ 처음 쓸 때
1. 아이콘을 누르고 「모델 받기」로 번역 모델을 한 번 내려받습니다(언어 쌍마다 한 번, Chrome 전체에서 함께 씁니다).
2. 「켜기」를 누르거나 ⌘K / Ctrl+K 를 누르면 지금 페이지가 번역됩니다. 다음 방문에도 자동으로 붙게 하려면 접근을 허용합니다.
3. 사이트마다 처음 한 번은 Chrome이 페이지 안의 클릭을 요구합니다. 스위치가 「눌러서 번역 시작」으로 바뀌면 한 번 눌러 주세요.

■ 필요한 권한
- 저장 공간: 설정(사이트 목록, 언어, 표시 방식)을 저장합니다.
- 활성 탭·스크립팅: 아이콘을 누른 탭에 번역 스위치를 붙입니다.
- 사이트 접근(선택): 켜 둔 사이트를 다음에 열 때 자동으로 붙이기 위해, 사용자가 허용한 사이트에만 접근합니다.

Chrome 138 이상에서 동작합니다. 번역 품질은 Chrome 내장 번역기의 품질을 따릅니다.

## 카테고리
생산성 › 도구 (또는 접근성)

## 언어
한국어(기본), 영어 외 38개 화면 언어
