# Translate Switch - भाषांतर स्विच — Chrome वेब स्टोअर सूची (मराठी)

## Summary (≤132 chars)
Chrome च्या डिव्हाइसवरील भाषांतरकाराने फक्त निवडलेल्या भाषेचे भाषांतर करते. ⌘K / Ctrl+K ने चालू/बंद; मूळ पाहण्यासाठी होव्हर करा.

## Description
Translate Switch पेजवरील फक्त परदेशी भाषेतील वाक्ये तुमच्या भाषेत बदलते आणि बाकी सर्व काही जसेच्या तसे ठेवते. ते पेज पुन्हा लोड किंवा रेंडर करत नाही; ते Chrome चा अंगभूत, डिव्हाइसवरच चालणारा भाषांतरकार वापरते, त्यामुळे पेजचा मजकूर कधीही तुमच्या संगणकाबाहेर जात नाही.

तुम्ही वाचत असलेल्या पेजवर भाषांतर चालू किंवा बंद करण्यासाठी ⌘K (Mac) / Ctrl+K (Windows) दाबा. पेजवर स्विच आल्यानंतर टूलबारमधील आयकॉनवर क्लिक करण्याची गरज नाही.

वैशिष्ट्ये
- शॉर्टकट ⌘K (Mac) / Ctrl+K (Windows) भाषांतर लगेच चालू/बंद करतो; कोणत्याही कीबोर्ड लेआउटमध्ये चालतो.
- डिव्हाइसवरच भाषांतर (Chrome चा अंगभूत Translator API). पेजचा कोणताही मजकूर कोणत्याही सर्व्हरला पाठवला जात नाही.
- भाषांतरित मजकूर हलक्या पार्श्वभूमीने आणि ठिपक्यांच्या अधोरेषेने हायलाइट होतो; ओळखलेल्या भाषेसह मूळ मजकूर पाहण्यासाठी त्यावर होव्हर करा.
- स्रोत भाषा: आपोआप ओळख किंवा ठरावीक भाषा. लक्ष्य भाषा: Chrome समर्थित 39 भाषांपैकी कोणतीही (डीफॉल्ट तुमच्या ब्राउझरची भाषा).
- प्रत्येक साइटसाठी स्वतंत्रपणे चालू करा, किंवा एकदाच सर्व साइटना परवानगी द्या. पेज उघडताच आपोआप भाषांतर फक्त तुम्ही सेट केलेल्या साइटवरच होते; नव्या साइटवर स्विच दिसतो आणि तुम्ही ⌘K / Ctrl+K किंवा स्विचने ते चालू करता.
- स्विच बटण हलवता आणि लपवता येते; हायलाइटचा रंग बदलता येतो.
- इंटरफेस 40 भाषांमध्ये उपलब्ध.

पहिल्यांदा वापरताना
1. आयकॉनवर क्लिक करा आणि भाषांतर मॉडेल एकदा डाउनलोड करा ("मॉडेल डाउनलोड करा"; प्रत्येक भाषा-जोडीसाठी एकदा, संपूर्ण Chrome मध्ये सामायिक).
2. सध्याच्या पेजचे भाषांतर करण्यासाठी "चालू करा" वर क्लिक करा (किंवा ⌘K / Ctrl+K दाबा). पुढच्या भेटीत स्विच आपोआप जोडला जावा असे वाटत असल्यास साइट ॲक्सेसला परवानगी द्या.
3. प्रत्येक नव्या साइटवर पहिल्या भाषांतरापूर्वी Chrome पेजमध्ये एक क्लिक मागतो; स्विचवर "भाषांतर करण्यासाठी क्लिक करा" दिसल्यावर तो दाबा.

परवानग्या
- storage: तुमच्या सेटिंग्ज जतन करते.
- activeTab, scripting: तुम्ही ज्या टॅबमध्ये आयकॉनवर क्लिक केले, त्यात स्विच जोडते.
- पर्यायी साइट ॲक्सेस: फक्त तुम्ही स्पष्टपणे परवानगी दिलेल्या साइटसाठी, जेणेकरून पुढच्या वेळी स्विच आपोआप जोडला जाईल.

Chrome 138 किंवा त्यानंतरची आवृत्ती आवश्यक. भाषांतराची गुणवत्ता Chrome च्या अंगभूत भाषांतरकाराइतकीच आहे.
