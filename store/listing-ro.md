# Translate Switch - Comutator de traducere — fișa din Magazinul Chrome Web (română)

## Summary (≤132 chars)
Traduce doar limba aleasă, cu traducătorul Chrome de pe dispozitiv. ⌘K / Ctrl+K pornește/oprește; treceți cursorul pentru original.

## Description
Translate Switch înlocuiește pe o pagină doar propozițiile în limbă străină cu limba dvs. și lasă restul neschimbat. Nu reîncarcă și nu redesenează pagina; folosește traducătorul integrat al Chrome, care rulează pe dispozitiv, așa că conținutul paginii nu părăsește niciodată computerul dvs.

Apăsați ⌘K (Mac) / Ctrl+K (Windows) pentru a porni sau opri traducerea paginii pe care o citiți. Odată ce comutatorul este pe pagină, nu mai trebuie să dați clic pe pictograma din bara de instrumente.

Funcții
- Comanda rapidă ⌘K (Mac) / Ctrl+K (Windows) pornește și oprește instantaneu traducerea; funcționează cu orice aspect de tastatură.
- Traducere pe dispozitiv (Translator API integrat în Chrome). Niciun conținut al paginii nu este trimis către vreun server.
- Textul tradus este evidențiat cu fundal deschis și subliniere punctată; treceți cursorul peste el pentru a vedea originalul și limba detectată.
- Limba sursă: detectare automată sau o limbă fixă. Limba țintă: oricare dintre cele 39 de limbi acceptate de Chrome (implicit, limba browserului).
- Activați-l pe fiecare site în parte sau permiteți o singură dată toate site-urile. Traducerea automată la deschiderea paginii se aplică doar site-urilor pentru care ați setat-o; pe un site nou apare doar comutatorul, iar traducerea o porniți cu ⌘K / Ctrl+K sau din comutator.
- Butonul comutatorului poate fi mutat și ascuns; culoarea de evidențiere este configurabilă.
- Interfață disponibilă în 40 de limbi.

Prima utilizare
1. Dați clic pe pictogramă și descărcați o singură dată modelul de traducere cu „Descărcați modelul” (pentru fiecare pereche de limbi; partajat în tot Chrome).
2. Dați clic pe „Activați” (sau apăsați ⌘K / Ctrl+K) pentru a traduce pagina curentă. Permiteți accesul la site dacă doriți ca acel comutator să apară automat la următoarea vizită.
3. Pe fiecare site nou, Chrome cere un clic în pagină înainte de prima traducere; apăsați comutatorul când afișează „Faceți clic pentru a traduce”.

Permisiuni
- storage: salvează setările dvs.
- activeTab, scripting: atașează comutatorul la fila în care ați dat clic pe pictogramă.
- Acces opțional la site-uri: doar pentru site-urile pe care le permiteți explicit, ca să poată apărea comutatorul automat data viitoare.

Necesită Chrome 138 sau o versiune ulterioară. Calitatea traducerii este cea a traducătorului integrat în Chrome.
