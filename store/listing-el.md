# Translate Switch - Διακόπτης μετάφρασης — Καταχώριση στο Chrome Web Store (Ελληνικά)

## Summary (≤132 chars)
Μεταφράζει μόνο τη γλώσσα που επιλέγετε με τον μεταφραστή του Chrome στη συσκευή. ⌘K / Ctrl+K εναλλαγή· δείξτε για το πρωτότυπο.

## Description
Το Translate Switch αντικαθιστά στη σελίδα μόνο τις προτάσεις σε ξένη γλώσσα με τη δική σας και αφήνει όλα τα υπόλοιπα ανέγγιχτα. Δεν φορτώνει ούτε αποδίδει ξανά τη σελίδα· χρησιμοποιεί τον ενσωματωμένο μεταφραστή του Chrome, που λειτουργεί στη συσκευή, οπότε το περιεχόμενο των σελίδων δεν φεύγει ποτέ από τον υπολογιστή σας.

Πατήστε ⌘K (Mac) / Ctrl+K (Windows) για να ενεργοποιήσετε ή να απενεργοποιήσετε τη μετάφραση στη σελίδα που διαβάζετε. Μόλις ο διακόπτης βρίσκεται στη σελίδα, δεν χρειάζεται να κάνετε κλικ στο εικονίδιο της γραμμής εργαλείων.

Λειτουργίες
- Η συντόμευση ⌘K (Mac) / Ctrl+K (Windows) ενεργοποιεί και απενεργοποιεί αμέσως τη μετάφραση· λειτουργεί με οποιαδήποτε διάταξη πληκτρολογίου.
- Μετάφραση στη συσκευή (ενσωματωμένο Translator API του Chrome). Κανένα περιεχόμενο της σελίδας δεν αποστέλλεται σε διακομιστή.
- Το μεταφρασμένο κείμενο επισημαίνεται με ανοιχτόχρωμο φόντο και διακεκομμένη υπογράμμιση· τοποθετήστε τον δείκτη από πάνω για να δείτε το πρωτότυπο και τη γλώσσα που εντοπίστηκε.
- Γλώσσα προέλευσης: αυτόματος εντοπισμός ή σταθερή γλώσσα. Γλώσσα προορισμού: οποιαδήποτε από τις 39 γλώσσες που υποστηρίζει το Chrome (προεπιλογή η γλώσσα του προγράμματος περιήγησης).
- Ενεργοποίηση ανά ιστότοπο ή άδεια για όλους τους ιστότοπους μία φορά. Η αυτόματη μετάφραση κατά το άνοιγμα σελίδας ισχύει μόνο για τους ιστότοπους που έχετε ορίσει· σε νέο ιστότοπο εμφανίζεται ο διακόπτης και την ενεργοποιείτε με ⌘K / Ctrl+K ή με τον διακόπτη.
- Κουμπί διακόπτη που μετακινείται και αποκρύπτεται· ρυθμιζόμενο χρώμα επισήμανσης.
- Περιβάλλον χρήσης σε 40 γλώσσες.

Πρώτη χρήση
1. Κάντε κλικ στο εικονίδιο και κατεβάστε μία φορά το μοντέλο μετάφρασης («Λήψη μοντέλου»· μία φορά ανά ζεύγος γλωσσών, κοινό για όλο το Chrome).
2. Κάντε κλικ στην «Ενεργοποίηση» (ή πατήστε ⌘K / Ctrl+K) για να μεταφράσετε την τρέχουσα σελίδα. Επιτρέψτε την πρόσβαση στον ιστότοπο αν θέλετε ο διακόπτης να εμφανίζεται αυτόματα στην επόμενη επίσκεψη.
3. Σε κάθε νέο ιστότοπο το Chrome απαιτεί ένα κλικ μέσα στη σελίδα πριν από την πρώτη μετάφραση· πατήστε τον διακόπτη όταν γράφει «Κάντε κλικ για μετάφραση».

Άδειες
- storage: αποθηκεύει τις ρυθμίσεις σας.
- activeTab, scripting: προσθέτει τον διακόπτη στην καρτέλα όπου κάνατε κλικ στο εικονίδιο.
- Προαιρετική πρόσβαση σε ιστότοπους: μόνο σε όσους επιτρέψετε ρητά, ώστε ο διακόπτης να εμφανίζεται αυτόματα την επόμενη φορά.

Απαιτεί Chrome 138 ή νεότερη έκδοση. Η ποιότητα της μετάφρασης είναι αυτή του ενσωματωμένου μεταφραστή του Chrome.
