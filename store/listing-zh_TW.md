# Translate Switch - 翻譯開關 — Chrome 線上應用程式商店介紹（繁體中文）

## Summary (≤132 chars)
使用 Chrome 內建的裝置端翻譯器，只翻譯你選擇的語言。按 ⌘K / Ctrl+K 即可切換翻譯，滑鼠移到上方即可查看原文。

## Description
Translate Switch（翻譯開關）只會把網頁中的外語句子換成你的語言，其餘內容維持原樣。它不會重新載入或重新轉譯網頁；它使用 Chrome 內建的裝置端翻譯器，網頁內容絕不會離開你的電腦。

按下 ⌘K (Mac) / Ctrl+K (Windows) 即可開啟或關閉正在閱讀的網頁的翻譯。網頁上已有開關時，不必點選工具列圖示。

功能
- 快速鍵 ⌘K (Mac) / Ctrl+K (Windows) 立即切換翻譯；適用於任何鍵盤配置。
- 裝置端翻譯（Chrome 內建的 Translator API），網頁內容不會傳送到任何伺服器。
- 已翻譯的文字會以淺色背景和點狀底線標示；將滑鼠移到上方即可查看原文及偵測到的語言。
- 來源語言：自動偵測或指定語言。目標語言：可從 Chrome 支援的 39 種語言中任選（預設為瀏覽器語言）。
- 可依網站開啟，也可一次授權所有網站。開啟網頁時的自動翻譯只會在你設定的網站上進行；在新網站上只會加上開關，可透過 ⌘K / Ctrl+K 或開關開啟翻譯。
- 開關按鈕可移動、可隱藏；醒目顯示顏色可自訂。
- 介面支援 40 種語言。

首次使用
1. 點選圖示，透過「下載模型」下載一次翻譯模型（每個語言組合只需一次，整個 Chrome 共用）。
2. 點選「開啟」（或按 ⌘K / Ctrl+K）即可翻譯目前網頁。如果希望下次造訪時自動加上開關，請允許網站存取權。
3. 在每個新網站上，Chrome 會要求首次翻譯前先在網頁內點選一次；當開關顯示「點選即可翻譯」時，請按下它。

權限
- storage：儲存你的設定。
- activeTab、scripting：在你點選圖示的分頁上加上開關。
- 選用的網站存取權：僅限你明確允許的網站，以便下次自動加上開關。

需要 Chrome 138 以上版本。翻譯品質取決於 Chrome 內建翻譯器。
