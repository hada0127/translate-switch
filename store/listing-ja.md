# Translate Switch - 翻訳スイッチ — Chrome ウェブストア掲載情報（日本語）

## Summary (≤132 chars)
選んだ言語だけを Chrome 内蔵の翻訳機能でデバイス内翻訳。⌘K / Ctrl+K ですぐにオン・オフでき、カーソルを合わせると原文を表示します。

## Description
Translate Switch（翻訳スイッチ）は、ページ内の外国語の文だけをあなたの言語に置き換え、それ以外はそのまま残します。ページの再読み込みや再描画は行いません。Chrome 内蔵のデバイス内翻訳機能を使うため、ページの内容がパソコンの外に送られることはありません。

⌘K (Mac) / Ctrl+K (Windows) を押すだけで、表示中のページの翻訳をオン・オフできます。スイッチが付いているページなら、ツールバーのアイコンをクリックする必要はありません。

主な機能
- ショートカット ⌘K (Mac) / Ctrl+K (Windows) で翻訳をすぐにオン・オフ。日本語キーボードを含め、どのキーボード配列でも動作します。
- デバイス内で翻訳（Chrome 内蔵の Translator API）。ページの内容をサーバーに送信することはありません。
- 翻訳したテキストは薄い背景と点線の下線で表示され、カーソルを合わせると原文と検出された言語を確認できます。
- 翻訳元の言語は自動検出または固定。翻訳先は Chrome が対応する 39 言語から選べます（既定はブラウザの言語）。
- サイトごとにオンにするか、一度の許可ですべてのサイトで使えます。ページを開いたときの自動翻訳は、設定したサイトでのみ行われます。初めてのサイトではスイッチが付くだけなので、⌘K / Ctrl+K またはスイッチでオンにします。
- スイッチボタンは移動・非表示が可能。ハイライトの色も変更できます。
- UI は 40 言語に対応しています。

はじめての使い方
1. アイコンをクリックし、「モデルをダウンロード」で翻訳モデルを一度だけダウンロードします（言語の組み合わせごとに一度。Chrome 全体で共有されます）。
2. 「オンにする」をクリック（または ⌘K / Ctrl+K を押す）すると、表示中のページが翻訳されます。次回の訪問時に自動でスイッチを付けたい場合は、サイトへのアクセスを許可してください。
3. 新しいサイトでは、最初の翻訳の前に Chrome がページ内での 1 回のクリックを求めます。スイッチに「クリックして翻訳」と表示されたら押してください。

権限
- storage: 設定を保存します。
- activeTab、scripting: アイコンをクリックしたタブにスイッチを付けます。
- サイトへのアクセス（任意）: 明示的に許可したサイトにのみ使い、次回から自動でスイッチを付けます。

Chrome 138 以降が必要です。翻訳の品質は Chrome 内蔵の翻訳機能に準じます。
