# Translate Switch - สวิตช์แปลภาษา — ข้อมูลใน Chrome เว็บสโตร์ (ภาษาไทย)

## Summary (≤132 chars)
แปลเฉพาะภาษาที่คุณเลือกด้วยตัวแปลในเครื่องของ Chrome กด ⌘K / Ctrl+K เพื่อเปิด/ปิดได้ทันที และชี้เมาส์เพื่อดูต้นฉบับ

## Description
Translate Switch จะแทนที่เฉพาะประโยคภาษาต่างประเทศในหน้าเว็บด้วยภาษาของคุณ และคงส่วนอื่นไว้ตามเดิม โดยไม่โหลดหรือเรนเดอร์หน้าใหม่ และใช้ตัวแปลในตัวของ Chrome ที่ทำงานบนอุปกรณ์ เนื้อหาของหน้าจึงไม่ออกไปนอกคอมพิวเตอร์ของคุณ

กด ⌘K (Mac) / Ctrl+K (Windows) เพื่อเปิดหรือปิดการแปลของหน้าที่คุณกำลังอ่าน เมื่อหน้านั้นมีสวิตช์แล้ว ก็ไม่ต้องคลิกไอคอนบนแถบเครื่องมืออีก

ฟีเจอร์
- ปุ่มลัด ⌘K (Mac) / Ctrl+K (Windows) เปิด/ปิดการแปลได้ทันที ใช้ได้กับแป้นพิมพ์ทุกรูปแบบ
- แปลบนอุปกรณ์ (Translator API ในตัวของ Chrome) ไม่มีการส่งเนื้อหาของหน้าไปยังเซิร์ฟเวอร์ใด ๆ
- ข้อความที่แปลแล้วจะแสดงด้วยพื้นหลังสีอ่อนและขีดเส้นใต้แบบจุด ชี้เมาส์เพื่อดูต้นฉบับพร้อมภาษาที่ตรวจพบ
- ภาษาต้นทาง: ตรวจหาอัตโนมัติหรือกำหนดภาษาตายตัว ภาษาปลายทาง: เลือกได้จาก 39 ภาษาที่ Chrome รองรับ (ค่าเริ่มต้นคือภาษาของเบราว์เซอร์)
- เปิดใช้เป็นรายเว็บไซต์ หรืออนุญาตทุกเว็บไซต์ในครั้งเดียว การแปลอัตโนมัติเมื่อเปิดหน้าจะทำเฉพาะเว็บไซต์ที่คุณตั้งไว้ ส่วนเว็บไซต์ใหม่จะมีเพียงสวิตช์ และคุณเปิดการแปลได้ด้วย ⌘K / Ctrl+K หรือสวิตช์
- ย้ายหรือซ่อนปุ่มสวิตช์ได้ และปรับสีไฮไลต์ได้
- หน้าจอรองรับ 40 ภาษา

การใช้งานครั้งแรก
1. คลิกไอคอนแล้วกด "ดาวน์โหลดโมเดล" เพื่อดาวน์โหลดโมเดลการแปลครั้งเดียว (ครั้งเดียวต่อคู่ภาษา และใช้ร่วมกันทั้ง Chrome)
2. คลิก "เปิด" (หรือกด ⌘K / Ctrl+K) เพื่อแปลหน้าปัจจุบัน หากต้องการให้สวิตช์ติดมาอัตโนมัติในการเข้าชมครั้งถัดไป ให้อนุญาตการเข้าถึงเว็บไซต์
3. ในแต่ละเว็บไซต์ใหม่ Chrome ต้องการให้คลิกในหน้าหนึ่งครั้งก่อนการแปลครั้งแรก เมื่อสวิตช์แสดง "คลิกเพื่อแปล" ให้กดสวิตช์

สิทธิ์
- storage: บันทึกการตั้งค่าของคุณ
- activeTab, scripting: ติดสวิตช์ไว้ที่แท็บที่คุณคลิกไอคอน
- การเข้าถึงเว็บไซต์ (ไม่บังคับ): เฉพาะเว็บไซต์ที่คุณอนุญาตอย่างชัดเจน เพื่อให้สวิตช์ติดมาอัตโนมัติในครั้งถัดไป

ต้องใช้ Chrome 138 ขึ้นไป คุณภาพการแปลเป็นไปตามตัวแปลในตัวของ Chrome
