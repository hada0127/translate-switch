# Translate Switch - மொழிபெயர்ப்பு விசை — Chrome இணைய அங்காடிப் பட்டியல் (தமிழ்)

## Summary (≤132 chars)
தேர்ந்த மொழியை மட்டும் Chrome-இன் சாதன மொழிபெயர்ப்பியால் மாற்றும். ⌘K / Ctrl+K இயக்கு/நிறுத்து; மேலே வைத்தால் மூலம் தெரியும்.

## Description
Translate Switch ஒரு பக்கத்தில் உள்ள வெளிநாட்டு மொழி வாக்கியங்களை மட்டும் உங்கள் மொழிக்கு மாற்றுகிறது; மற்ற அனைத்தையும் அப்படியே விட்டுவிடுகிறது. இது பக்கத்தை மீண்டும் ஏற்றுவதோ மீண்டும் வரைவதோ இல்லை. Chrome-இல் உள்ளமைந்த, சாதனத்திலேயே இயங்கும் மொழிபெயர்ப்பியைப் பயன்படுத்துவதால், பக்க உள்ளடக்கம் உங்கள் கணினியை விட்டு வெளியே செல்லாது.

நீங்கள் படிக்கும் பக்கத்தின் மொழிபெயர்ப்பை இயக்க அல்லது நிறுத்த ⌘K (Mac) / Ctrl+K (Windows) அழுத்துங்கள். பக்கத்தில் விசை இணைந்த பிறகு, கருவிப்பட்டி ஐகானைக் கிளிக் செய்ய வேண்டியதில்லை.

அம்சங்கள்
- ⌘K (Mac) / Ctrl+K (Windows) குறுக்குவிசை மொழிபெயர்ப்பை உடனே இயக்கும்/நிறுத்தும்; எந்த விசைப்பலகை அமைப்பிலும் வேலை செய்யும்.
- சாதனத்திலேயே மொழிபெயர்ப்பு (Chrome-இன் உள்ளமைந்த Translator API). பக்க உள்ளடக்கம் எந்தச் சேவையகத்துக்கும் அனுப்பப்படாது.
- மொழிபெயர்க்கப்பட்ட உரை வெளிர் பின்னணியுடனும் புள்ளிக் கோட்டு அடிக்கோடுடனும் காட்டப்படும்; சுட்டியை மேலே வைத்தால் மூல உரையும் கண்டறியப்பட்ட மொழியும் தெரியும்.
- மூல மொழி: தானியங்கு கண்டறிதல் அல்லது நிலையான மொழி. இலக்கு மொழி: Chrome ஆதரிக்கும் 39 மொழிகளில் ஏதேனும் ஒன்று (இயல்பாக உங்கள் உலாவியின் மொழி).
- தளவாரியாக இயக்கலாம், அல்லது ஒருமுறை அனுமதித்து எல்லாத் தளங்களிலும் பயன்படுத்தலாம். பக்கம் திறக்கும்போது தானியங்கு மொழிபெயர்ப்பு நீங்கள் அமைத்த தளங்களில் மட்டுமே நடக்கும்; புதிய தளத்தில் விசை மட்டும் இணையும், மொழிபெயர்ப்பை ⌘K / Ctrl+K அல்லது விசை மூலம் இயக்கலாம்.
- விசைப் பொத்தானை நகர்த்தலாம், மறைக்கலாம்; தனிப்படுத்தும் நிறத்தை மாற்றலாம்.
- 40 மொழிகளில் இடைமுகம்.

முதல் பயன்பாடு
1. ஐகானைக் கிளிக் செய்து "மாதிரியைப் பதிவிறக்கு" மூலம் மொழிபெயர்ப்பு மாதிரியை ஒருமுறை பதிவிறக்குங்கள் (ஒவ்வொரு மொழி இணைக்கும் ஒருமுறை; Chrome முழுவதும் பகிரப்படும்).
2. தற்போதைய பக்கத்தை மொழிபெயர்க்க "இயக்கு" என்பதைக் கிளிக் செய்யுங்கள் (அல்லது ⌘K / Ctrl+K அழுத்துங்கள்). அடுத்த முறை விசை தானாக இணைய வேண்டுமெனில் தள அணுகலை அனுமதியுங்கள்.
3. ஒவ்வொரு புதிய தளத்திலும் முதல் மொழிபெயர்ப்புக்கு முன் பக்கத்துக்குள் ஒரு கிளிக்கை Chrome கேட்கும்; விசையில் "மொழிபெயர்க்க கிளிக் செய்யுங்கள்" எனத் தெரிந்தால் அதை அழுத்துங்கள்.

அனுமதிகள்
- storage: உங்கள் அமைப்புகளைச் சேமிக்கிறது.
- activeTab, scripting: நீங்கள் ஐகானைக் கிளிக் செய்த தாவலில் விசையை இணைக்கிறது.
- விருப்பத் தள அணுகல்: நீங்கள் வெளிப்படையாக அனுமதிக்கும் தளங்களுக்கு மட்டும், அடுத்த முறை விசை தானாக இணைவதற்காக.

Chrome 138 அல்லது அதற்குப் பிந்தைய பதிப்பு தேவை. மொழிபெயர்ப்புத் தரம் Chrome-இன் உள்ளமைந்த மொழிபெயர்ப்பியின் தரத்தைப் பொறுத்தது.
