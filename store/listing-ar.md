# Translate Switch - مفتاح الترجمة — بطاقة سوق Chrome الإلكتروني (العربية)

## Summary (≤132 chars)
يترجم اللغة التي تختارها فقط بمترجم Chrome المدمج على جهازك. ⌘K / Ctrl+K للتشغيل والإيقاف؛ مرّر المؤشر لرؤية النص الأصلي.

## Description
يستبدل Translate Switch الجمل المكتوبة بلغة أجنبية فقط في الصفحة بلغتك، ويترك كل ما عداها كما هو. لا يعيد تحميل الصفحة ولا يعيد عرضها؛ بل يستخدم مترجم Chrome المدمج الذي يعمل على جهازك، فلا يغادر محتوى الصفحات حاسوبك أبدًا.

اضغط ⌘K (Mac) / Ctrl+K (Windows) لتشغيل الترجمة أو إيقافها في الصفحة التي تقرؤها. وبمجرد ظهور المفتاح في الصفحة، لا حاجة إلى النقر على الأيقونة في شريط الأدوات.

الميزات
- اختصار ⌘K (Mac) / Ctrl+K (Windows) يشغّل الترجمة ويوقفها فورًا، ويعمل مع أي تخطيط للوحة المفاتيح.
- ترجمة على الجهاز (واجهة Translator API المدمجة في Chrome). لا يُرسَل أي محتوى من الصفحة إلى أي خادم.
- يُميَّز النص المترجم بخلفية فاتحة وخط سفلي منقّط؛ مرّر المؤشر فوقه لرؤية النص الأصلي مع اللغة المكتشفة.
- لغة المصدر: اكتشاف تلقائي أو لغة محددة. اللغة الهدف: أي لغة من اللغات الـ 39 التي يدعمها Chrome (افتراضيًا لغة متصفحك).
- شغّله لكل موقع على حدة، أو اسمح بجميع المواقع مرة واحدة. الترجمة التلقائية عند فتح الصفحة تنطبق فقط على المواقع التي ضبطتها لها؛ وفي أي موقع جديد يظهر المفتاح وتشغّله باختصار ⌘K / Ctrl+K أو بالمفتاح نفسه.
- زر مفتاح قابل للنقل والإخفاء، ولون تمييز قابل للتخصيص.
- واجهة متاحة بـ 40 لغة.

الاستخدام الأول
1. انقر على الأيقونة ونزّل نموذج الترجمة مرة واحدة («تنزيل النموذج»؛ مرة لكل زوج لغات، ويُستخدم بشكل مشترك في Chrome كله).
2. انقر على «تشغيل» (أو اضغط ⌘K / Ctrl+K) لترجمة الصفحة الحالية. اسمح بالوصول إلى الموقع إذا أردت أن يظهر المفتاح تلقائيًا في زيارتك القادمة.
3. في كل موقع جديد يطلب Chrome نقرة واحدة داخل الصفحة قبل أول ترجمة؛ اضغط المفتاح عندما تظهر عليه عبارة «انقر للترجمة».

الأذونات
- storage: يحفظ إعداداتك.
- activeTab وscripting: يضيف المفتاح إلى علامة التبويب التي نقرت فيها على الأيقونة.
- الوصول الاختياري إلى المواقع: فقط للمواقع التي تسمح بها صراحةً، حتى يظهر المفتاح تلقائيًا في المرة القادمة.

يتطلب Chrome 138 أو إصدارًا أحدث. جودة الترجمة هي جودة مترجم Chrome المدمج.
