# Translate Switch - ಅನುವಾದ ಸ್ವಿಚ್ — Chrome ವೆಬ್ ಸ್ಟೋರ್ ಪಟ್ಟಿ (ಕನ್ನಡ)

## Summary (≤132 chars)
Chrome ನ ಸಾಧನದೊಳಗಿನ ಅನುವಾದಕದಿಂದ ನೀವು ಆರಿಸಿದ ಭಾಷೆಯನ್ನು ಮಾತ್ರ ಅನುವಾದಿಸುತ್ತದೆ. ⌘K / Ctrl+K ಆನ್/ಆಫ್; ಮೂಲ ನೋಡಲು ಹೋವರ್ ಮಾಡಿ.

## Description
Translate Switch ಪುಟದಲ್ಲಿರುವ ವಿದೇಶಿ ಭಾಷೆಯ ವಾಕ್ಯಗಳನ್ನು ಮಾತ್ರ ನಿಮ್ಮ ಭಾಷೆಗೆ ಬದಲಿಸುತ್ತದೆ ಮತ್ತು ಉಳಿದೆಲ್ಲವನ್ನೂ ಹಾಗೆಯೇ ಬಿಡುತ್ತದೆ. ಇದು ಪುಟವನ್ನು ಮರುಲೋಡ್ ಅಥವಾ ಮರುರೆಂಡರ್ ಮಾಡುವುದಿಲ್ಲ; Chrome ನ ಅಂತರ್ನಿರ್ಮಿತ, ಸಾಧನದಲ್ಲೇ ಚಲಿಸುವ ಅನುವಾದಕವನ್ನು ಬಳಸುತ್ತದೆ, ಹಾಗಾಗಿ ಪುಟದ ವಿಷಯ ಎಂದಿಗೂ ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನಿಂದ ಹೊರಹೋಗುವುದಿಲ್ಲ.

ನೀವು ಓದುತ್ತಿರುವ ಪುಟದಲ್ಲಿ ಅನುವಾದವನ್ನು ಆನ್ ಅಥವಾ ಆಫ್ ಮಾಡಲು ⌘K (Mac) / Ctrl+K (Windows) ಒತ್ತಿ. ಪುಟದಲ್ಲಿ ಸ್ವಿಚ್ ಬಂದ ನಂತರ ಟೂಲ್‌ಬಾರ್ ಐಕಾನ್ ಕ್ಲಿಕ್ ಮಾಡುವ ಅಗತ್ಯವಿಲ್ಲ.

ವೈಶಿಷ್ಟ್ಯಗಳು
- ಶಾರ್ಟ್‌ಕಟ್ ⌘K (Mac) / Ctrl+K (Windows) ತಕ್ಷಣ ಅನುವಾದವನ್ನು ಆನ್/ಆಫ್ ಮಾಡುತ್ತದೆ; ಯಾವುದೇ ಕೀಬೋರ್ಡ್ ಲೇಔಟ್‌ನಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ.
- ಸಾಧನದಲ್ಲೇ ಅನುವಾದ (Chrome ನ ಅಂತರ್ನಿರ್ಮಿತ Translator API). ಪುಟದ ಯಾವುದೇ ವಿಷಯವನ್ನು ಯಾವುದೇ ಸರ್ವರ್‌ಗೆ ಕಳುಹಿಸಲಾಗುವುದಿಲ್ಲ.
- ಅನುವಾದಿತ ಪಠ್ಯವನ್ನು ತಿಳಿ ಹಿನ್ನೆಲೆ ಮತ್ತು ಚುಕ್ಕೆ ಅಡಿಗೆರೆಯಿಂದ ಹೈಲೈಟ್ ಮಾಡಲಾಗುತ್ತದೆ; ಪತ್ತೆಯಾದ ಭಾಷೆಯೊಂದಿಗೆ ಮೂಲ ಪಠ್ಯ ನೋಡಲು ಅದರ ಮೇಲೆ ಹೋವರ್ ಮಾಡಿ.
- ಮೂಲ ಭಾಷೆ: ಸ್ವಯಂ ಪತ್ತೆ ಅಥವಾ ನಿಗದಿತ ಭಾಷೆ. ಗುರಿ ಭಾಷೆ: Chrome ಬೆಂಬಲಿಸುವ 39 ಭಾಷೆಗಳಲ್ಲಿ ಯಾವುದಾದರೂ (ಡೀಫಾಲ್ಟ್ ನಿಮ್ಮ ಬ್ರೌಸರ್ ಭಾಷೆ).
- ಪ್ರತಿ ಸೈಟ್‌ಗೆ ಪ್ರತ್ಯೇಕವಾಗಿ ಆನ್ ಮಾಡಿ, ಅಥವಾ ಒಮ್ಮೆಗೇ ಎಲ್ಲಾ ಸೈಟ್‌ಗಳಿಗೆ ಅನುಮತಿಸಿ. ಪುಟ ತೆರೆದಾಗ ಸ್ವಯಂ ಅನುವಾದ ನೀವು ಹೊಂದಿಸಿದ ಸೈಟ್‌ಗಳಲ್ಲಿ ಮಾತ್ರ ನಡೆಯುತ್ತದೆ; ಹೊಸ ಸೈಟ್‌ನಲ್ಲಿ ಸ್ವಿಚ್ ಕಾಣಿಸಿಕೊಳ್ಳುತ್ತದೆ ಮತ್ತು ನೀವು ⌘K / Ctrl+K ಅಥವಾ ಸ್ವಿಚ್ ಮೂಲಕ ಆನ್ ಮಾಡುತ್ತೀರಿ.
- ಸ್ವಿಚ್ ಬಟನ್ ಅನ್ನು ಸರಿಸಬಹುದು ಮತ್ತು ಮರೆಮಾಡಬಹುದು; ಹೈಲೈಟ್ ಬಣ್ಣವನ್ನು ಬದಲಿಸಬಹುದು.
- 40 ಭಾಷೆಗಳಲ್ಲಿ ಇಂಟರ್‌ಫೇಸ್.

ಮೊದಲ ಬಳಕೆ
1. ಐಕಾನ್ ಕ್ಲಿಕ್ ಮಾಡಿ ಮತ್ತು ಅನುವಾದ ಮಾದರಿಯನ್ನು ಒಮ್ಮೆ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ ("ಮಾದರಿ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ"; ಪ್ರತಿ ಭಾಷಾ ಜೋಡಿಗೆ ಒಮ್ಮೆ, ಇಡೀ Chrome ನಲ್ಲಿ ಹಂಚಿಕೊಳ್ಳಲಾಗುತ್ತದೆ).
2. ಪ್ರಸ್ತುತ ಪುಟವನ್ನು ಅನುವಾದಿಸಲು "ಆನ್ ಮಾಡಿ" ಕ್ಲಿಕ್ ಮಾಡಿ (ಅಥವಾ ⌘K / Ctrl+K ಒತ್ತಿ). ಮುಂದಿನ ಭೇಟಿಯಲ್ಲಿ ಸ್ವಿಚ್ ತಾನಾಗಿಯೇ ಸೇರಬೇಕೆಂದರೆ ಸೈಟ್ ಪ್ರವೇಶವನ್ನು ಅನುಮತಿಸಿ.
3. ಪ್ರತಿ ಹೊಸ ಸೈಟ್‌ನಲ್ಲಿ ಮೊದಲ ಅನುವಾದದ ಮೊದಲು Chrome ಪುಟದೊಳಗೆ ಒಂದು ಕ್ಲಿಕ್ ಕೇಳುತ್ತದೆ; ಸ್ವಿಚ್‌ನಲ್ಲಿ "ಅನುವಾದಿಸಲು ಕ್ಲಿಕ್ ಮಾಡಿ" ಎಂದು ಕಂಡಾಗ ಅದನ್ನು ಒತ್ತಿ.

ಅನುಮತಿಗಳು
- storage: ನಿಮ್ಮ ಸೆಟ್ಟಿಂಗ್‌ಗಳನ್ನು ಉಳಿಸುತ್ತದೆ.
- activeTab, scripting: ನೀವು ಐಕಾನ್ ಕ್ಲಿಕ್ ಮಾಡಿದ ಟ್ಯಾಬ್‌ಗೆ ಸ್ವಿಚ್ ಸೇರಿಸುತ್ತದೆ.
- ಐಚ್ಛಿಕ ಸೈಟ್ ಪ್ರವೇಶ: ನೀವು ಸ್ಪಷ್ಟವಾಗಿ ಅನುಮತಿಸಿದ ಸೈಟ್‌ಗಳಿಗೆ ಮಾತ್ರ, ಇದರಿಂದ ಮುಂದಿನ ಬಾರಿ ಸ್ವಿಚ್ ತಾನಾಗಿಯೇ ಸೇರಬಹುದು.

Chrome 138 ಅಥವಾ ನಂತರದ ಆವೃತ್ತಿ ಅಗತ್ಯ. ಅನುವಾದದ ಗುಣಮಟ್ಟ Chrome ನ ಅಂತರ್ನಿರ್ಮಿತ ಅನುವಾದಕದ ಗುಣಮಟ್ಟದಷ್ಟೇ.
