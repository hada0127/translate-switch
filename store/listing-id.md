# Translate Switch - Sakelar Terjemahan — Listingan Chrome Web Store (Bahasa Indonesia)

## Summary (≤132 chars)
Menerjemahkan hanya bahasa pilihan Anda dengan penerjemah lokal Chrome. ⌘K / Ctrl+K aktif/nonaktif; arahkan kursor untuk teks asli.

## Description
Translate Switch hanya mengganti kalimat berbahasa asing di halaman dengan bahasa Anda dan membiarkan bagian lain apa adanya. Halaman tidak dimuat ulang atau dirender ulang; ekstensi ini memakai penerjemah bawaan Chrome yang berjalan di perangkat, sehingga konten halaman tidak pernah keluar dari komputer Anda.

Tekan ⌘K (Mac) / Ctrl+K (Windows) untuk mengaktifkan atau menonaktifkan terjemahan pada halaman yang sedang Anda baca. Setelah sakelar ada di halaman, Anda tidak perlu mengklik ikon di toolbar.

Fitur
- Pintasan ⌘K (Mac) / Ctrl+K (Windows) langsung mengaktifkan dan menonaktifkan terjemahan; berfungsi dengan tata letak keyboard apa pun.
- Terjemahan di perangkat (Translator API bawaan Chrome). Tidak ada konten halaman yang dikirim ke server mana pun.
- Teks terjemahan ditandai dengan latar terang dan garis bawah putus-putus; arahkan kursor untuk melihat teks asli beserta bahasa yang terdeteksi.
- Bahasa sumber: deteksi otomatis atau bahasa tetap. Bahasa tujuan: salah satu dari 39 bahasa yang didukung Chrome (default-nya bahasa browser Anda).
- Aktifkan per situs, atau izinkan semua situs sekaligus. Terjemahan otomatis saat halaman dibuka hanya berlaku di situs yang Anda atur; di situs baru, sakelar akan muncul dan Anda mengaktifkannya dengan ⌘K / Ctrl+K atau sakelar itu.
- Tombol sakelar bisa dipindah dan disembunyikan; warna sorotan bisa diatur.
- Antarmuka tersedia dalam 40 bahasa.

Penggunaan pertama
1. Klik ikon dan unduh model terjemahan sekali saja ("Unduh model"; sekali per pasangan bahasa, dipakai bersama di seluruh Chrome).
2. Klik "Aktifkan" (atau tekan ⌘K / Ctrl+K) untuk menerjemahkan halaman saat ini. Izinkan akses situs jika Anda ingin sakelar muncul otomatis pada kunjungan berikutnya.
3. Di setiap situs baru, Chrome mewajibkan satu klik di dalam halaman sebelum terjemahan pertama; tekan sakelar saat tertulis "Klik untuk menerjemahkan".

Izin
- storage: menyimpan setelan Anda.
- activeTab, scripting: memasang sakelar di tab tempat Anda mengklik ikon.
- Akses situs opsional: hanya untuk situs yang Anda izinkan secara tegas, agar sakelar bisa muncul otomatis lain kali.

Memerlukan Chrome 138 atau yang lebih baru. Kualitas terjemahan mengikuti penerjemah bawaan Chrome.
