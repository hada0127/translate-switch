# Translate Switch — Chrome Web Store listing (English)

## Summary (≤132 chars)
Translates only the language you pick with Chrome's on-device translator. ⌘K / Ctrl+K to toggle; hover to see the original.

## Description
Translate Switch replaces only the foreign-language sentences on a page with your language and leaves everything else untouched. It does not reload or re-render the page; it uses Chrome's built-in, on-device translator, so page content never leaves your computer.

Press ⌘K (Mac) / Ctrl+K (Windows) to turn translation on or off for the page you are reading. Once the switch is on a page, there is no need to click the toolbar icon.

Features
- Shortcut ⌘K (Mac) / Ctrl+K (Windows) toggles translation instantly; works with any keyboard layout.
- On-device translation (Chrome's built-in Translator API). No page content is sent to any server.
- Translated text is highlighted with a light background and dotted underline; hover to see the original with its detected language.
- Source language: automatic detection or a fixed language. Target: any of the 39 languages Chrome supports (defaults to your browser language).
- Turn it on per site, or allow all sites once. Automatic translation on page open applies only to sites you set it for; on a new site the switch attaches and you turn it on with ⌘K / Ctrl+K or the switch.
- Movable, hideable switch button; configurable highlight color.
- UI available in 40 languages.

First use
1. Click the icon and download the translation model once (per language pair; shared across Chrome).
2. Click "Turn on" (or press ⌘K / Ctrl+K) to translate the current page. Allow site access if you want it to attach automatically on your next visit.
3. On each new site Chrome requires one click inside the page before the first translation; press the switch when it says "Click to translate".

Permissions
- storage: saves your settings.
- activeTab, scripting: attaches the switch to the tab where you clicked the icon.
- Optional site access: only for sites you explicitly allow, so the switch can attach automatically next time.

Requires Chrome 138 or later. Translation quality is that of Chrome's built-in translator.
