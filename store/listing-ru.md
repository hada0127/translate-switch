# Translate Switch - Переключатель перевода — описание в Интернет-магазине Chrome (русский)

## Summary (≤132 chars)
Переводит только выбранный язык встроенным переводчиком Chrome на устройстве. ⌘K / Ctrl+K — вкл./выкл.; наведите — увидите оригинал.

## Description
Translate Switch заменяет на странице только предложения на иностранном языке вашим языком, а всё остальное оставляет без изменений. Страница не перезагружается и не перерисовывается; расширение использует встроенный переводчик Chrome, работающий на устройстве, поэтому содержимое страницы никогда не покидает ваш компьютер.

Нажмите ⌘K (Mac) / Ctrl+K (Windows), чтобы включить или выключить перевод страницы, которую вы читаете. Когда переключатель уже есть на странице, нажимать на значок на панели инструментов не нужно.

Возможности
- Сочетание клавиш ⌘K (Mac) / Ctrl+K (Windows) мгновенно включает и выключает перевод; работает с любой раскладкой клавиатуры.
- Перевод на устройстве (встроенный в Chrome Translator API). Содержимое страниц не отправляется ни на какие серверы.
- Переведённый текст выделяется светлым фоном и пунктирным подчёркиванием; наведите курсор, чтобы увидеть оригинал и определённый язык.
- Исходный язык: автоопределение или заданный язык. Язык перевода: любой из 39 языков, которые поддерживает Chrome (по умолчанию — язык браузера).
- Включайте для отдельных сайтов или один раз разрешите все сайты. Автоматический перевод при открытии страницы работает только на сайтах, где вы его настроили; на новом сайте появляется только переключатель, а перевод включается через ⌘K / Ctrl+K или сам переключатель.
- Кнопку переключателя можно перемещать и скрывать; цвет выделения настраивается.
- Интерфейс на 40 языках.

Первый запуск
1. Нажмите на значок и один раз загрузите модель перевода кнопкой «Скачать модель» (для каждой языковой пары; модель общая для всего Chrome).
2. Нажмите «Включить» (или ⌘K / Ctrl+K), чтобы перевести текущую страницу. Разрешите доступ к сайту, если хотите, чтобы переключатель появлялся автоматически при следующем посещении.
3. На каждом новом сайте Chrome требует один щелчок по странице перед первым переводом; нажмите переключатель, когда на нём появится «Нажмите, чтобы перевести».

Разрешения
- storage: сохраняет ваши настройки.
- activeTab, scripting: добавляет переключатель на вкладку, где вы нажали на значок.
- Необязательный доступ к сайтам: только к тем сайтам, которые вы явно разрешили, чтобы в следующий раз переключатель появлялся автоматически.

Требуется Chrome 138 или новее. Качество перевода соответствует встроенному переводчику Chrome.
