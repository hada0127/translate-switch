# Translate Switch - 翻译开关 — Chrome 应用商店介绍（简体中文）

## Summary (≤132 chars)
用 Chrome 内置的设备端翻译器，只翻译你选择的语言。按 ⌘K / Ctrl+K 即可开关翻译，鼠标悬停即可查看原文。

## Description
Translate Switch（翻译开关）只会把网页中的外语句子替换成你的语言，其余内容保持不变。它不会重新加载或重新渲染网页；它使用 Chrome 内置的设备端翻译器，网页内容绝不会离开你的电脑。

按 ⌘K (Mac) / Ctrl+K (Windows) 即可开启或关闭正在阅读的网页的翻译。页面上已有开关时，无需点击工具栏图标。

功能
- 快捷键 ⌘K (Mac) / Ctrl+K (Windows) 一键开关翻译；适用于任何键盘布局。
- 设备端翻译（Chrome 内置的 Translator API），网页内容不会发送到任何服务器。
- 已翻译的文字以浅色背景和点状下划线标示；鼠标悬停即可查看原文及检测到的语言。
- 源语言：自动检测或指定语言。目标语言：可从 Chrome 支持的 39 种语言中任选（默认为浏览器语言）。
- 可按网站开启，也可一次授权所有网站。打开网页时的自动翻译仅在你设置过的网站上进行；在新网站上只会附加开关，可通过 ⌘K / Ctrl+K 或开关开启翻译。
- 开关按钮可移动、可隐藏；高亮颜色可自定义。
- 界面支持 40 种语言。

首次使用
1. 点击图标，通过“下载模型”下载一次翻译模型（每个语言对只需一次，整个 Chrome 共用）。
2. 点击“开启”（或按 ⌘K / Ctrl+K）即可翻译当前网页。如果希望下次访问时自动附加开关，请允许网站访问权限。
3. 在每个新网站上，Chrome 要求首次翻译前在页面内点击一次；当开关显示“点击即可翻译”时，请点按它。

权限
- storage：保存你的设置。
- activeTab、scripting：在你点击图标的标签页上附加开关。
- 可选的网站访问权限：仅限你明确允许的网站，以便下次自动附加开关。

需要 Chrome 138 或更高版本。翻译质量取决于 Chrome 内置翻译器。
