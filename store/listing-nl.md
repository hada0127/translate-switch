# Translate Switch - Vertaalschakelaar — Chrome Web Store-vermelding (Nederlands)

## Summary (≤132 chars)
Vertaalt alleen de gekozen taal met de vertaler van Chrome, op je apparaat. ⌘K / Ctrl+K zet het aan/uit; hover voor het origineel.

## Description
Translate Switch vervangt alleen de zinnen in een vreemde taal op een pagina door jouw taal en laat de rest ongemoeid. De pagina wordt niet opnieuw geladen of opgebouwd; de extensie gebruikt de ingebouwde vertaler van Chrome die op je apparaat draait, dus de pagina-inhoud verlaat je computer nooit.

Druk op ⌘K (Mac) / Ctrl+K (Windows) om de vertaling van de pagina die je leest aan of uit te zetten. Staat de schakelaar eenmaal op een pagina, dan hoef je niet meer op het pictogram in de werkbalk te klikken.

Functies
- Sneltoets ⌘K (Mac) / Ctrl+K (Windows) zet de vertaling direct aan of uit; werkt met elke toetsenbordindeling.
- Vertaling op het apparaat (de ingebouwde Translator API van Chrome). Er wordt geen pagina-inhoud naar een server gestuurd.
- Vertaalde tekst krijgt een lichte achtergrond en een gestippelde onderstreping; beweeg de muis erover om het origineel en de herkende taal te zien.
- Brontaal: automatisch herkennen of een vaste taal. Doeltaal: elk van de 39 talen die Chrome ondersteunt (standaard de taal van je browser).
- Zet het per site aan, of geef eenmalig toestemming voor alle sites. Automatisch vertalen bij het openen van een pagina gebeurt alleen op sites waarvoor je dat instelt; op een nieuwe site verschijnt alleen de schakelaar en zet je de vertaling aan met ⌘K / Ctrl+K of de schakelaar.
- Verplaatsbare, verbergbare schakelknop; instelbare markeerkleur.
- Interface beschikbaar in 40 talen.

Eerste gebruik
1. Klik op het pictogram en download het vertaalmodel eenmalig met ‘Model downloaden’ (per taalpaar; gedeeld binnen heel Chrome).
2. Klik op ‘Inschakelen’ (of druk op ⌘K / Ctrl+K) om de huidige pagina te vertalen. Sta sitetoegang toe als je wilt dat de schakelaar bij je volgende bezoek automatisch verschijnt.
3. Op elke nieuwe site vraagt Chrome vóór de eerste vertaling om één klik op de pagina; druk op de schakelaar wanneer die ‘Klik om te vertalen’ toont.

Rechten
- storage: slaat je instellingen op.
- activeTab, scripting: plaatst de schakelaar op het tabblad waar je op het pictogram hebt geklikt.
- Optionele sitetoegang: alleen voor sites die je uitdrukkelijk toestaat, zodat de schakelaar de volgende keer automatisch verschijnt.

Vereist Chrome 138 of hoger. De vertaalkwaliteit is die van de ingebouwde vertaler van Chrome.
