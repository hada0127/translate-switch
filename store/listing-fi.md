# Translate Switch - Käännöskytkin — Chrome Web Store -kuvaus (suomi)

## Summary (≤132 chars)
Kääntää vain valitsemasi kielen Chromen laitteella toimivalla kääntäjällä. ⌘K / Ctrl+K päälle/pois; alkuperäinen näkyy osoittamalla.

## Description
Translate Switch korvaa sivulla vain vieraskieliset lauseet omalla kielelläsi ja jättää kaiken muun ennalleen. Sivua ei ladata eikä piirretä uudelleen: käännöksen tekee Chromen sisäänrakennettu kääntäjä suoraan laitteella, joten sivun sisältö ei koskaan poistu tietokoneeltasi.

Paina ⌘K (Mac) / Ctrl+K (Windows) kytkeäksesi käännöksen päälle tai pois lukemallasi sivulla. Kun kytkin on jo sivulla, työkalupalkin kuvaketta ei tarvitse napsauttaa.

Ominaisuudet
- Pikanäppäin ⌘K (Mac) / Ctrl+K (Windows) kytkee käännöksen päälle ja pois heti; toimii kaikilla näppäimistöasetteluilla.
- Käännös laitteella (Chromen sisäänrakennettu Translator API). Sivun sisältöä ei lähetetä millekään palvelimelle.
- Käännetty teksti korostetaan vaalealla taustalla ja pisteviivalla; vie osoitin tekstin päälle nähdäksesi alkuperäisen ja tunnistetun kielen.
- Lähdekieli: automaattinen tunnistus tai kiinteä kieli. Kohdekieli: mikä tahansa Chromen tukemasta 39 kielestä (oletuksena selaimesi kieli).
- Ota käyttöön sivustokohtaisesti tai salli kaikki sivustot kerralla. Automaattinen käännös sivun avautuessa koskee vain sivustoja, joille olet sen asettanut; uudella sivustolla kytkin ilmestyy, ja otat käännöksen käyttöön näppäimillä ⌘K / Ctrl+K tai kytkimestä.
- Siirrettävä ja piilotettava kytkinpainike; korostusvärin voi valita.
- Käyttöliittymä 40 kielellä.

Ensimmäinen käyttökerta
1. Napsauta kuvaketta ja lataa käännösmalli kerran (”Lataa malli”; kerran kieliparia kohden, yhteinen koko Chromelle).
2. Napsauta ”Ota käyttöön” (tai paina ⌘K / Ctrl+K) kääntääksesi nykyisen sivun. Salli sivuston käyttöoikeus, jos haluat kytkimen ilmestyvän automaattisesti seuraavalla käynnillä.
3. Jokaisella uudella sivustolla Chrome vaatii yhden napsautuksen sivulla ennen ensimmäistä käännöstä; paina kytkintä, kun siinä lukee ”Käännä napsauttamalla”.

Käyttöoikeudet
- storage: tallentaa asetuksesi.
- activeTab, scripting: lisää kytkimen välilehteen, jossa napsautit kuvaketta.
- Valinnainen sivustojen käyttöoikeus: vain sivustoille, jotka erikseen sallit, jotta kytkin voi ilmestyä automaattisesti seuraavalla kerralla.

Vaatii Chrome 138:n tai uudemman. Käännöksen laatu on Chromen sisäänrakennetun kääntäjän laatua.
