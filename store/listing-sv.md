# Translate Switch - Översättningsknapp — beskrivning i Chrome Web Store (svenska)

## Summary (≤132 chars)
Översätter bara språket du väljer med Chromes inbyggda översättare på enheten. ⌘K / Ctrl+K slår på/av; hovra för originalet.

## Description
Translate Switch ersätter bara meningarna på främmande språk på en sida med ditt språk och lämnar allt annat orört. Sidan laddas inte om och ritas inte om; tillägget använder Chromes inbyggda översättare som körs på enheten, så sidans innehåll lämnar aldrig din dator.

Tryck på ⌘K (Mac) / Ctrl+K (Windows) för att slå på eller av översättningen för sidan du läser. När knappen väl finns på sidan behöver du inte klicka på ikonen i verktygsfältet.

Funktioner
- Kortkommandot ⌘K (Mac) / Ctrl+K (Windows) slår på och av översättningen direkt; fungerar med alla tangentbordslayouter.
- Översättning på enheten (Chromes inbyggda Translator API). Inget sidinnehåll skickas till någon server.
- Översatt text markeras med ljus bakgrund och prickad understrykning; hovra för att se originalet och det identifierade språket.
- Källspråk: automatisk identifiering eller ett fast språk. Målspråk: valfritt av de 39 språk som Chrome stöder (standard är webbläsarens språk).
- Slå på det per webbplats, eller tillåt alla webbplatser en gång. Automatisk översättning när en sida öppnas gäller bara webbplatser där du har ställt in det; på en ny webbplats visas bara knappen och du slår på översättningen med ⌘K / Ctrl+K eller knappen.
- Flyttbar knapp som går att dölja; valfri markeringsfärg.
- Gränssnitt på 40 språk.

Första användningen
1. Klicka på ikonen och ladda ned översättningsmodellen en gång med ”Ladda ned modell” (per språkpar; delas i hela Chrome).
2. Klicka på ”Slå på” (eller tryck på ⌘K / Ctrl+K) för att översätta den aktuella sidan. Tillåt webbplatsåtkomst om du vill att knappen ska visas automatiskt vid nästa besök.
3. På varje ny webbplats kräver Chrome ett klick på sidan före den första översättningen; tryck på knappen när den visar ”Klicka för att översätta”.

Behörigheter
- storage: sparar dina inställningar.
- activeTab, scripting: lägger till knappen på fliken där du klickade på ikonen.
- Valfri webbplatsåtkomst: bara för webbplatser du uttryckligen tillåter, så att knappen kan visas automatiskt nästa gång.

Kräver Chrome 138 eller senare. Översättningskvaliteten motsvarar Chromes inbyggda översättare.
