# Translate Switch - অনুবাদ সুইচ — Chrome ওয়েব স্টোর তালিকা (বাংলা)

## Summary (≤132 chars)
Chrome-এর অন-ডিভাইস অনুবাদক দিয়ে শুধু আপনার বাছাই করা ভাষা অনুবাদ করে। ⌘K / Ctrl+K দিয়ে চালু/বন্ধ; মূল লেখা দেখতে হোভার করুন।

## Description
Translate Switch পেজের শুধু বিদেশি ভাষার বাক্যগুলোকে আপনার ভাষায় বদলে দেয় এবং বাকি সব যেমন আছে তেমনই রাখে। এটি পেজ আবার লোড বা রেন্ডার করে না; Chrome-এর বিল্ট-ইন, ডিভাইসেই চলা অনুবাদক ব্যবহার করে, তাই পেজের বিষয়বস্তু কখনো আপনার কম্পিউটারের বাইরে যায় না।

আপনি যে পেজ পড়ছেন তাতে অনুবাদ চালু বা বন্ধ করতে ⌘K (Mac) / Ctrl+K (Windows) চাপুন। পেজে সুইচ বসে গেলে টুলবারের আইকনে ক্লিক করার দরকার নেই।

বৈশিষ্ট্য
- শর্টকাট ⌘K (Mac) / Ctrl+K (Windows) সঙ্গে সঙ্গে অনুবাদ চালু/বন্ধ করে; যেকোনো কিবোর্ড লেআউটে কাজ করে।
- ডিভাইসেই অনুবাদ (Chrome-এর বিল্ট-ইন Translator API)। পেজের কোনো বিষয়বস্তু কোনো সার্ভারে পাঠানো হয় না।
- অনূদিত লেখা হালকা ব্যাকগ্রাউন্ড ও ডটেড আন্ডারলাইনে হাইলাইট হয়; শনাক্ত করা ভাষাসহ মূল লেখা দেখতে তার ওপর হোভার করুন।
- উৎস ভাষা: স্বয়ংক্রিয় শনাক্তকরণ বা নির্দিষ্ট ভাষা। লক্ষ্য ভাষা: Chrome-সমর্থিত 39টি ভাষার যেকোনোটি (ডিফল্ট আপনার ব্রাউজারের ভাষা)।
- প্রতিটি সাইটের জন্য আলাদা করে চালু করুন, অথবা একবারে সব সাইটের অনুমতি দিন। পেজ খোলার সময় স্বয়ংক্রিয় অনুবাদ শুধু সেই সাইটগুলোতে হয় যেগুলোর জন্য আপনি এটি সেট করেছেন; নতুন সাইটে সুইচ দেখা যায়, আর আপনি ⌘K / Ctrl+K বা সুইচ দিয়ে চালু করেন।
- সুইচ বোতাম সরানো ও লুকানো যায়; হাইলাইটের রং বদলানো যায়।
- 40টি ভাষায় ইন্টারফেস।

প্রথমবার ব্যবহার
1. আইকনে ক্লিক করে অনুবাদ মডেল একবার ডাউনলোড করুন ("মডেল ডাউনলোড করুন"; প্রতিটি ভাষা-জোড়ার জন্য একবার, পুরো Chrome জুড়ে শেয়ার করা)।
2. বর্তমান পেজ অনুবাদ করতে "চালু করুন"-এ ক্লিক করুন (বা ⌘K / Ctrl+K চাপুন)। পরের বার এলে সুইচ যেন নিজে থেকে বসে যায়, চাইলে সাইট অ্যাক্সেসের অনুমতি দিন।
3. প্রতিটি নতুন সাইটে প্রথম অনুবাদের আগে Chrome পেজের ভেতরে একটি ক্লিক চায়; সুইচে "অনুবাদ করতে ক্লিক করুন" দেখালে সেটি চাপুন।

অনুমতি
- storage: আপনার সেটিংস সংরক্ষণ করে।
- activeTab, scripting: যে ট্যাবে আপনি আইকনে ক্লিক করেছেন, সেখানে সুইচ যুক্ত করে।
- ঐচ্ছিক সাইট অ্যাক্সেস: শুধু সেই সাইটগুলোর জন্য যেগুলোর আপনি স্পষ্টভাবে অনুমতি দেন, যাতে পরের বার সুইচ নিজে থেকে যুক্ত হতে পারে।

Chrome 138 বা তার পরের সংস্করণ প্রয়োজন। অনুবাদের মান Chrome-এর বিল্ট-ইন অনুবাদকের মানের মতোই।
