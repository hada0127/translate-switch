# Translate Switch - అనువాద స్విచ్ — Chrome వెబ్ స్టోర్ జాబితా (తెలుగు)

## Summary (≤132 chars)
మీరు ఎంచుకున్న భాషను మాత్రమే Chrome పరికరంలోని అనువాదకంతో అనువదిస్తుంది. ⌘K / Ctrl+K తో ఆన్/ఆఫ్; పాయింటర్ ఉంచితే అసలు కనిపిస్తుంది.

## Description
Translate Switch ఒక పేజీలోని విదేశీ భాషా వాక్యాలను మాత్రమే మీ భాషలోకి మారుస్తుంది, మిగతావన్నీ అలాగే ఉంచుతుంది. ఇది పేజీని మళ్లీ లోడ్ చేయదు, మళ్లీ రెండర్ చేయదు; Chrome లో అంతర్నిర్మితమైన, పరికరంలోనే పనిచేసే అనువాదకాన్ని ఉపయోగిస్తుంది, కాబట్టి పేజీ కంటెంట్ మీ కంప్యూటర్‌ను దాటి ఎప్పుడూ బయటకు వెళ్లదు.

మీరు చదువుతున్న పేజీ అనువాదాన్ని ఆన్ లేదా ఆఫ్ చేయడానికి ⌘K (Mac) / Ctrl+K (Windows) నొక్కండి. పేజీకి స్విచ్ జోడించిన తర్వాత టూల్‌బార్ ఐకాన్‌ను క్లిక్ చేయాల్సిన అవసరం లేదు.

ఫీచర్లు
- ⌘K (Mac) / Ctrl+K (Windows) షార్ట్‌కట్‌తో అనువాదాన్ని వెంటనే ఆన్/ఆఫ్ చేయండి; ఏ కీబోర్డ్ లేఅవుట్‌తోనైనా పనిచేస్తుంది.
- పరికరంలోనే అనువాదం (Chrome అంతర్నిర్మిత Translator API). పేజీ కంటెంట్ ఏ సర్వర్‌కూ పంపబడదు.
- అనువదించిన వచనం లేత నేపథ్యం, చుక్కల అండర్‌లైన్‌తో హైలైట్ అవుతుంది; పాయింటర్ ఉంచితే అసలు వచనం, గుర్తించిన భాష కనిపిస్తాయి.
- మూల భాష: ఆటోమేటిక్ గుర్తింపు లేదా స్థిరమైన భాష. లక్ష్య భాష: Chrome మద్దతిచ్చే 39 భాషల్లో ఏదైనా (డిఫాల్ట్‌గా మీ బ్రౌజర్ భాష).
- సైట్ వారీగా ఆన్ చేయండి, లేదా ఒక్కసారి అనుమతించి అన్ని సైట్లలో ఉపయోగించండి. పేజీ తెరిచినప్పుడు ఆటోమేటిక్ అనువాదం మీరు సెట్ చేసిన సైట్లలో మాత్రమే జరుగుతుంది; కొత్త సైట్‌లో స్విచ్ మాత్రమే జోడించబడుతుంది, అనువాదాన్ని ⌘K / Ctrl+K లేదా స్విచ్‌తో ఆన్ చేయండి.
- స్విచ్ బటన్‌ను జరపవచ్చు, దాచవచ్చు; హైలైట్ రంగును మార్చుకోవచ్చు.
- 40 భాషల్లో ఇంటర్‌ఫేస్.

మొదటి వినియోగం
1. ఐకాన్‌ను క్లిక్ చేసి "మోడల్‌ను డౌన్‌లోడ్ చేయి" తో అనువాద మోడల్‌ను ఒక్కసారి డౌన్‌లోడ్ చేయండి (ప్రతి భాషా జతకు ఒక్కసారి; Chrome అంతటా పంచుకోబడుతుంది).
2. ప్రస్తుత పేజీని అనువదించడానికి "ఆన్ చేయండి" క్లిక్ చేయండి (లేదా ⌘K / Ctrl+K నొక్కండి). తదుపరి సందర్శనలో స్విచ్ ఆటోమేటిక్‌గా జోడించబడాలంటే సైట్ యాక్సెస్‌ను అనుమతించండి.
3. ప్రతి కొత్త సైట్‌లో మొదటి అనువాదానికి ముందు పేజీలో ఒక క్లిక్‌ను Chrome కోరుతుంది; స్విచ్‌పై "అనువదించడానికి క్లిక్ చేయండి" కనిపించినప్పుడు దాన్ని నొక్కండి.

అనుమతులు
- storage: మీ సెట్టింగ్‌లను సేవ్ చేస్తుంది.
- activeTab, scripting: మీరు ఐకాన్‌ను క్లిక్ చేసిన ట్యాబ్‌కు స్విచ్‌ను జోడిస్తుంది.
- ఐచ్ఛిక సైట్ యాక్సెస్: మీరు స్పష్టంగా అనుమతించిన సైట్లకు మాత్రమే, తదుపరిసారి స్విచ్ ఆటోమేటిక్‌గా జోడించబడేందుకు.

Chrome 138 లేదా ఆ తర్వాతి వెర్షన్ అవసరం. అనువాద నాణ్యత Chrome అంతర్నిర్మిత అనువాదకం నాణ్యతపై ఆధారపడి ఉంటుంది.
