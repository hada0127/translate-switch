# Translate Switch - Перемикач перекладу — опис в Інтернет-магазині Chrome (українська)

## Summary (≤132 chars)
Перекладає лише вибрану мову вбудованим перекладачем Chrome на пристрої. ⌘K / Ctrl+K — увімк./вимк.; наведіть — побачите оригінал.

## Description
Translate Switch замінює на сторінці лише речення іноземною мовою вашою мовою, а все інше залишає без змін. Сторінка не перезавантажується й не перемальовується; розширення використовує вбудований перекладач Chrome, що працює на пристрої, тож вміст сторінки ніколи не залишає ваш комп’ютер.

Натисніть ⌘K (Mac) / Ctrl+K (Windows), щоб увімкнути або вимкнути переклад сторінки, яку ви читаєте. Коли перемикач уже є на сторінці, натискати значок на панелі інструментів не потрібно.

Можливості
- Комбінація клавіш ⌘K (Mac) / Ctrl+K (Windows) миттєво вмикає й вимикає переклад; працює з будь-якою розкладкою клавіатури.
- Переклад на пристрої (вбудований у Chrome Translator API). Вміст сторінок не надсилається на жодні сервери.
- Перекладений текст виділяється світлим тлом і пунктирним підкресленням; наведіть курсор, щоб побачити оригінал і визначену мову.
- Мова оригіналу: автовизначення або задана мова. Мова перекладу: будь-яка з 39 мов, які підтримує Chrome (за замовчуванням — мова браузера).
- Вмикайте для окремих сайтів або один раз дозвольте всі сайти. Автоматичний переклад під час відкриття сторінки працює лише на сайтах, де ви його налаштували; на новому сайті з’являється тільки перемикач, а переклад вмикається через ⌘K / Ctrl+K або сам перемикач.
- Кнопку перемикача можна переміщати й приховувати; колір виділення налаштовується.
- Інтерфейс 40 мовами.

Перший запуск
1. Натисніть значок і один раз завантажте модель перекладу кнопкою «Завантажити модель» (для кожної мовної пари; модель спільна для всього Chrome).
2. Натисніть «Увімкнути» (або ⌘K / Ctrl+K), щоб перекласти поточну сторінку. Дозвольте доступ до сайту, якщо хочете, щоб перемикач з’являвся автоматично під час наступного відвідування.
3. На кожному новому сайті Chrome вимагає одного клацання на сторінці перед першим перекладом; натисніть перемикач, коли на ньому з’явиться «Натисніть, щоб перекласти».

Дозволи
- storage: зберігає ваші налаштування.
- activeTab, scripting: додає перемикач на вкладку, де ви натиснули значок.
- Необов’язковий доступ до сайтів: лише до сайтів, які ви явно дозволили, щоб наступного разу перемикач з’являвся автоматично.

Потрібен Chrome 138 або новіший. Якість перекладу відповідає вбудованому перекладачу Chrome.
